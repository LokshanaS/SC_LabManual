# 🌦️ Weather App

A simple and responsive Weather App that provides real-time weather updates for any city using a weather API. Built with a clean UI and fast performance, this project helps users check current weather conditions instantly.

---

## 🚀 Features

* 🌍 Search weather by city name
* 🌡️ Real-time temperature updates
* ☁️ Weather conditions with icons
* 💨 Wind speed, humidity, and pressure
* 📱 Responsive design for mobile and desktop
* ⚡ Fast and lightweight application

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Version Control:** Git & GitHub

---

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/LokshanaS/weather-app.git
```

2. Navigate to the project folder

```bash
cd weather-app
```

3. Open `index.html` in your browser

---

## 🔑 API Setup

1. Get your free API key from
   [OpenWeatherMap](https://openweathermap.org/api?utm_source=chatgpt.com)

2. Replace the API key in your JavaScript file

```js
const apiKey = "YOUR_API_KEY";
```
